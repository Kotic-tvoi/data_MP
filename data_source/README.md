# data_source

Это текстовый источник базы знаний. Эти файлы можно читать и обновлять через GitHub/чат.

Главное правило: SQLite является сборочным артефактом, а не ручным источником данных.

- `products.csv` — справочник товаров и артикулов.
- `questions/YYYY.jsonl` — вопросы клиентов, разбитые по годам.
- `faq_templates.jsonl` — готовые FAQ-шаблоны.
- `forbidden_phrases.jsonl` — запрещённые и корректные формулировки.
- `synonyms.jsonl` — синонимы для поиска.
- `manual_updates.jsonl` — новые записи, которые можно добавлять через чат.
